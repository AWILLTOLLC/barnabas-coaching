# Creel Project Overview

The Creel project focuses on the development of a native macOS OpenClaw client, serving as the official successor to the retired VantageOC system.

### Key Architectural Decisions
- **Native Implementation**: Developed as a native macOS application without the use of plugins.
- **System Transition**: Officially replaced **VantageOC** on 2026-03-18.

### Component Summary
- **creel_macos_client.md**: Details the transition from VantageOC and the native, plugin-free architecture of the macOS client.
- **creel_system.md**: Documents the status of Creel as the active replacement for the legacy system.
- **context.md**: Provides the high-level topic overview for Creel development.
