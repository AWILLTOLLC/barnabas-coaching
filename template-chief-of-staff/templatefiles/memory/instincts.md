# instincts.md — Learned Patterns

Purpose: patterns worth repeating and mistakes worth avoiding, in an atomic format so they can be matched mechanically and promoted into core files once well-evidenced.

Rules:
- One trigger, one action. Keep entries atomic.
- Start confidence at 0.6 or below. Raise it only when the pattern holds up across 2+ distinct sessions with citable evidence.
- Never promote a pattern into SOUL.md or AGENTS.md the same day it's first observed.
- Delete patterns that proved wrong.

## Format (EXAMPLE — do not keep this entry)

```
### [YYYY-MM-DD] Short title
**Trigger:** The specific situation that should fire this (one line).
**Action:** What to do (or not do) when the trigger fires (one line).
**Confidence:** 0.0-1.0 numeric
**Evidence:** What happened that taught this.
```
