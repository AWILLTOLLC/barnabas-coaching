# Content Ideas — Morse Command Instagram

**Last updated:** 2026-03-30
**Status:** Staging area — add ideas freely, move to content-calendar.md when scheduled

---

## Niche Audit: Overused Patterns to Avoid

1. The Morse alphabet chart infographic
2. Shack tour "rate my setup" flexes
3. "Decode this message!" black screen + dots and dashes
4. License exam flex selfies
5. POTA scenery with no hook or tension
6. "Morse code is used in…" trivia carousels
7. Straight key close-up + audio (genre default)
8. "Did you know ham radio helped during [disaster]?" — earnest, uncinematic
9. Demo-then-explain Reels that front-load tutorial content
10. Quote graphics ("In Morse, every character counts.")
