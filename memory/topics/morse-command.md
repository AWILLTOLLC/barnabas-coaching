# Morse Command

Tactical Morse Code learning game for ham radio operators and CW enthusiasts. Built on the Koch Method with adaptive AI.

## Overview

Morse Command is an iOS game that teaches Morse Code through 80 levels of tactical gameplay. The app uses the scientifically-proven Koch Method (full speed from day one, progressive character introduction) combined with adaptive AI that targets weak spots. Features include 8 boss battles, 8 enemy types, and tactical power-ups.

**Key facts:**
- 80 levels across 8 zones
- Koch Method engine for rapid fluency
- Adaptive AI that adjusts difficulty based on performance
- Little Kid Mode for family-friendly learning
- App Store: https://apps.apple.com/us/app/morse-code-defense/id6759479305
