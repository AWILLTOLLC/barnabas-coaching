### Key Discoveries

**OpenClaw channel plugin internals:**
- `message` tool validates targets via directory lookup, NOT `listAccountIds`
- Target bypasses directory if `plugin.messaging.targetResolver.looksLikeId(raw)` returns true
- Frame format for gateway WebSocket is `{ type: "req", id, method, params }` — NOT JSON-RPC
- Valid gateway client IDs: `gateway-client`, `openclaw-control-ui`, `webchat-ui`, `cli`, etc.
- Auth flow: receive `connect.challenge` event → send `connect` req with `{ auth: { token }, client: { id: "gateway-client", ... }, scopes: ["operator.admin"] }`
- Gateway is WebSocket-only for RPC — HTTP POST to `/rpc` returns "Not Found"
- `chat.send` requires `idempotencyKey` param
- `sessions.patch` only patches label/model settings — cannot set delivery context/channel routing
- `sendText` AND `sendMedia` both required for channel plugin outbound or handler returns null
- `sendText` receives `{ text, to, accountId, cfg, ... }` — `to` is the resolved target

**Session delivery routing:**
- Reply channel for `chat.send` comes from `entry.deliveryContext.channel ?? entry.lastChannel`
- `api.runtime.channel.session.recordSessionMetaFromInbound({ storePath, sessionKey, ctx })` creates/updates session with delivery context
- ctx fields: `OriginatingChannel`, `OriginatingTo`, `AccountId`, `Provider`, `Surface`, `ChatType`, `From`, `To`, `Body`, etc.
- `api.runtime.channel.session.resolveStorePath(sessionKey)` gets the store path

### Architecture Note
The vantage.message flow (final design):
1. Vantage sends `vantage.message` RPC with `{ text, channelId }`
2. Plugin calls `recordSessionMetaFromInbound` to create session `vantage-{channelId}` with delivery context `channel: vantage, to: channelId`
3. Plugin calls `chat.send` via internal WS loopback to session `vantage-{channelId}`
4. Agent processes, reply broadcasts as `chat` event with `sessionKey: vantage-{channelId}`
5. Vantage client routes that chat event to the right channel based on sessionKey
6. Reply also stored in `channel_messages` table via `sendText(to: channelId)`
