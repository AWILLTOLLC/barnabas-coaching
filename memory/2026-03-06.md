### Config Damage — Important
- Earlier today: tried adding channels.vantage to openclaw.json → gateway refused to start, Aaron had to restore old config
- Root cause: config validator rejects unknown channel IDs; external plugins are loaded AFTER validation so vantage channel is unknown at validation time
- Bundled plugins (in /usr/lib/node_modules/openclaw/extensions/) load BEFORE validation; external plugins (~/.openclaw/extensions/) load AFTER
- Conclusion: channels.vantage config block is permanently impossible for external plugins
