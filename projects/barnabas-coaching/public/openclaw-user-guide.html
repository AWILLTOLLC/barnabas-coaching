OpenClaw User Guide

Essential `/` Commands

🔄

Session Control

  • /reset Start fresh. Clears current context, keeps conversation history.
  • /compact Compresses conversation to fit model context limits.
  • /new Creates a brand new session from scratch.
  • /status Shows current session: model, token usage, time elapsed, cost.
🧠

Memory & Context

  • /memory Opens your memory workspace (MEMORY.md, daily notes, decisions, errors).
  • /search Search past sessions for specific topics or decisions.
  • /log View recent session history and logs.
🛠️

Deployment & Tools

  • /approve Grant elevated permissions (file edits, shell commands, config changes).
  • /deploy Trigger deployment of workspace changes (if configured).
⚙️

Model & Runtime

  • /model Show current model; use `/model <name>` to switch models.
  • /reasoning Toggle reasoning mode on/off (hidden until enabled).
  • /cost Show current session token cost.

Most Used in Practice

/reset When stuck in a context loop
/status Check model usage and cost
/compact When hitting context limits
/approve Before big changes
/model Switch between local/cloud models
