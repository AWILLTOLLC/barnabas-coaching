X2Claw Options

POST target for the JSON payload. Example: http://127.0.0.1:18789/hooks/x2claw

Sent as `Authorization: Bearer <token>`. Needed when the target is an OpenClaw gateway hook.

Prepended to every message. Example: "Analyze this post and tell me if it's worth a reply."

A slug alone on a line works too; the display name defaults to the slug. Lines starting with # are ignored.
