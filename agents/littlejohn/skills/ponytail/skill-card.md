## Description:

Lazy senior dev mode for any coding task (write, refactor, fix, review): YAGNI, stdlib first, no unrequested abstractions. Not for non-coding requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and coding agents use ponytail to keep coding work focused on minimal, standard-library-first changes, root-cause fixes, and concise code-focused responses.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill persistently biases coding work toward minimal diffs, standard-library-first choices, and short explanations.

Mitigation: Install it only when that coding posture is desired, and opt out with "stop ponytail" or "normal mode" when fuller design work or explanation is needed.

Risk: Over-minimizing changes can be inappropriate for trust boundaries, data-loss prevention, security measures, accessibility basics, or explicitly requested full implementations.

Mitigation: Review proposed simplifications against those boundaries before deployment or execution.
